# PredictIQ Original Control Tower Enhanced

This version preserves the original Control Tower layout and original `runScenario()` simulation, adds four source-results tabs below the Control Tower introduction, and adds the generated architecture visual.

Open `PredictIQ_Standalone.html` directly, or run `scripts/serve.ps1` and open http://localhost:8080. All displayed figures are synthetic.
